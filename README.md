# FARMA_SUS
Trabalho semestral - Profº João Victor
Funções

Problema:
-
Usuários que dependem da retirada de medicamentos pela SESPA podem enfrentar dificuldades
para obter informações sobre a situação de sua solicitação e sobre a disponibilidade do
medicamento. A ausência de uma ferramenta centralizada para acompanhamento dessas
informações pode resultar em deslocamentos desnecessários, perda de tempo e dificuldade para
saber quando o medicamento estará disponível para retirada.

Solução:
-
Desenvolver um sistema web que permita aos usuários acompanhar o processo de solicitação e
disponibilidade de medicamentos, desde o envio do laudo ou exame até a atualização do status
do medicamento para retirada.

Publico-alvo:
-
• Usuários do SUS que necessitam solicitar e retirar medicamentos disponibilizados pela
SESPA.

• Profissionais farmacêuticos responsáveis pela análise dos laudos e acompanhamento dos
medicamentos.

• Administradores responsáveis pelo gerenciamento dos usuários farmacêuticos e das
informações administrativas do sistema.

Front-end:
-
HTML5, CSS3 e JavaScript serão utilizados na construção da interface da aplicação. Essas
tecnologias permitem a criação de páginas web responsivas e acessíveis por navegadores em
computadores e dispositivos móveis.

Back-end:
-
Python será utilizado no desenvolvimento do back-end, sendo responsável pelo processamento
das requisições, aplicação das regras de negócio, autenticação e comunicação com o banco de
dados.

Banco de Dados:
-
O Cloud Firestore será utilizado como plataforma de banco de dados e serviços de apoio à
aplicação. Sua utilização permite trabalhar com banco de dados hospedado em nuvem e recursos
de autenticação e API.
